# Data and documentation license

The generated chord observations and this corpus documentation are licensed under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).

The source shape models are drawn from the [Database of Asteroid Models from Inversion Techniques (DAMIT)](https://damit.cuni.cz/projects/damit/). DAMIT says that site content is CC BY 4.0 except where otherwise stated. Each selected model has a source URL, SHA-256 digest and link to its original publication in `SOURCE_CATALOG_PUBLIC.json`. Cite the model's original publication and Ďurech et al. (2010), *DAMIT: a database of asteroid models*, A&A 513, A46, [DOI 10.1051/0004-6361/200912693](https://doi.org/10.1051/0004-6361/200912693), as DAMIT requests.

The generated profiles are synthetic. No historical occultation measurements are included.
